## 一、八行判断表（全部判断力在这）

| 你要拦的东西 | 这叫 | 用什么 |
|---|---|---|
| 类型不对 | 类型约束 | 类型注解本身（Pydantic 自动转/拦） |
| 值超出范围 | 数值边界 | `Field(ge=, le=)` |
| 长度不对 | 长度约束 | `Field(min_length=, max_length=)` |
| 出现约定外的字段 | 结构约束 | `ConfigDict(extra="forbid")` |
| 必填项没给 | 存在性 | 不给默认值就行 |
| 值只能是几个固定选项之一 | 枚举约束 | `Literal["ok", "refused"]` |
| 值合法但没意义（`"   "`） | 语义约束 | `field_validator` |
| 两个字段互相矛盾 | 跨字段约束 | `model_validator(mode="after")` |

## 二、最小模板（照抄，改字段就行）

```python
from __future__ import annotations

from typing import Literal

from pydantic import BaseModel, ConfigDict, Field, field_validator, model_validator


class Out(BaseModel):
    model_config = ConfigDict(extra="forbid")          # 多余字段直接报错

    answer: str = Field(min_length=1, description="给用户的回答")
    citations: list[str] = Field(default_factory=list, max_length=5)
    confidence: float = Field(ge=0.0, le=1.0)
    status: Literal["ok", "refused"] = "ok"

    @field_validator("answer")                          # 单字段语义
    @classmethod
    def _not_blank(cls, v: str) -> str:
        if not v.strip():
            raise ValueError("不能是空白字符串")
        return v.strip()                                # ← 必须 return

    @model_validator(mode="after")                      # 跨字段
    def _cross(self) -> Out:
        if self.status == "refused" and self.citations:
            raise ValueError("拒答时不应该附带引用")
        return self                                     # ← 必须 return
```

## 三、四个反直觉（都是实测结论）

| 反直觉 | 实测结果 |
|---|---|
| `" " * 3`（三个空格）能过 `min_length=1` 吗 | **能**。`len(" " * 3) == 3`，长度规则只数字符个数 |
| `field_validator` 对默认值运行吗 | **不运行**。不传那个字段，validator 一次都不执行 |
| `info.data` 里有什么 | **只有它前面已校验的字段**。把字段挪到前面，它就空了（静默失效） |
| 默认值受 `max_length` 约束吗 | **不受**。默认值是你写的，Pydantic 默认信任它（要校验得加 `validate_default=True`） |

## 四、三个必须写对的位置

1. `@field_validator("x")` **下面**必须跟 `@classmethod`（顺序反了**不报错**，validator 静默失效，实测）
2. validator 函数**最后必须 `return v` / `return self`**（忘了不报错，字段会变成 `None`，且类型注解被绕过，实测）
3. `extra="forbid"` 必须放 `model_config = ConfigDict(...)`，**不能**塞进 `Field()`

## 五、拼写清单（不用背，查这里）

| 名字 | 用途 |
|---|---|
| `BaseModel` | 基类 |
| `Field` | 加约束 / 默认值 / 说明 |
| `ConfigDict` | 类级配置（`extra`、`str_strip_whitespace`） |
| `field_validator` | 单字段校验 |
| `model_validator` | 跨字段校验 |
| `min_length` / `max_length` | 长度（字符串、列表都能用） |
| `ge` / `le` | ≥ / ≤（greater-equal / less-equal） |
| `default_factory` | 用函数造默认值（要加约束时必须用它） |
| `description` | 会进 JSON Schema，等于 prompt 的一部分 |
| `model_validate(dict)` | dict → 模型 |
| `model_dump_json()` | 模型 → JSON 字符串 |
| `model_json_schema()` | 模型 → JSON Schema |

## 六、自测（不看上面，先答再看）

1. `ge` 和 `le` 分别是哪两个英文词？
2. 要让模型多返回的字段直接报错，写哪个参数？
3. `@field_validator` 下一行必须是什么？
4. validator 函数最后一行必须是？
5. `s = " " * 3`（三个空格）能通过 `min_length=1` 吗？为什么？
6. 默认值 `["a","b","c","d"]` 配 `max_length=3`，构造时会报错吗？

<details>
<summary>答案</summary>

1. greater-or-equal / less-or-equal
2. `model_config = ConfigDict(extra="forbid")`
3. `@classmethod`
4. `return v`（`model_validator` 是 `return self`）
5. 能。`len(s) == 3`，`min_length` 只数字符个数，空格也是字符
6. 不报。默认值默认不参与校验

</details>
