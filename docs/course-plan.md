## 怎么上这门课

1. **一节课 = 一个主题 + 一段可跑代码 + 一条验收标准。** 讲不透的不讲，跑不起来的不算学会。
2. **输入输出比 1:3。** 看 1 小时，写 3 小时代码。文档优先于视频，视频只 1.5x 看、不跟敲。
3. **每 4 周一个可演示节点**（W4 / W8 / W12 / W16 / W20）。对着屏幕讲 10 分钟，讲不出来就是没学会。
4. **每周日 1 小时**写周报，更新下面的进度表和能力矩阵。

## VS Code 一次性配置（已建好，不用再动）

`.vscode/` 下三个文件，跟着仓库走。**换电脑 clone 下来就自动生效，不用重新选解释器。**

| 文件 | 干什么 | 效果 |
|---|---|---|
| `settings.json` | 把 `.venv\Scripts\python.exe` 定为默认解释器；打开终端自动激活 venv；启用 pytest；类型检查设为 basic | 开项目就是对的 Python，不再弹"选择解释器" |
| `launch.json` | 三条运行配置，`python` 字段写死 venv 路径 | F5 跑当前文件 / F5 跑全部 pytest，永远用对解释器 |
| `extensions.json` | 推荐 Python + Pylance | 首次打开会提示安装 |

第一次打开文件夹时只有一件事要手动做：**点顶部横幅的「信任」**。VS Code 会永久记住这个文件夹，以后不再问。

常用入口（配好之后）：

| 想做的事 | 操作 |
|---|---|
| 跑当前文件 | `F5` → 选「运行当前文件（不调试）」 |
| 跑全部测试 | 左侧烧瓶图标 → Run All；或 `F5` → 选「pytest 全部」 |
| 开终端 | `Ctrl + \``（自动激活 venv，提示符前带 `(.venv)`） |

## 项目 A：企业知识库问答（项目驱动主线，2026-11-17 完成 v1）

路线文件里项目 A 原定 W7 开工。实际提前到 W2 之后，因为 W2 学的四节（类型校验/重试/装饰器/流式）
正好就是调用层的全部原料。周次内容改为「卡住时补给」。

语料：桌面 `DataMining pdf` 五份讲义（chap03/04a/04b/04c/05，共 199 页）。
选它的原因：正在学的课，答案对错能自己判断 —— 这是建黄金集的前提。

| 里程碑 | 产物 | 验收（全部实测） |
|---|---|---|
| M1 调用层 | `llmkit/` — ask / ask_structured / stream_ask + 配置 + 异常分类 + JSON 日志 | 70 条离线测试；DeepSeek 真实调用六种场景全通（401 不重试 203ms、连接失败退避重试 3 次） |
| M2 语料层 | `corpus/` — 黄金集 18 题 / PDF 解析 / 切分 / 落盘 | 199 页解析；181 块，中位 507 字；18 条出处页码机械核对全中 |
| M3 检索层 | `retrieval/` — BM25 + 中文查询翻译 | hit@5 **94%**、MRR 0.769；不翻译基线 72%（对比见 `retrieval/eval_retrieval.py`） |
| M4 生成评估 | `qa/` — prompt + 引用解析 + 双轨判分 | top_k=5 **17/18 correct**；top_k=8 **18/18**；引用越界 0；3 个语料外问题全部拒绝作答 |

全项目 **283 条测试**（w02 78 / llmkit 70 / corpus 90 / retrieval 25 / qa 20），全程离线可跑。

一条命令复现评估：

```bash
python -m corpus.store save          # PDF → artifacts/chunks.jsonl（2.1 秒）
python -m corpus.eval_chunking       # 切分方案对比矩阵
python -m retrieval.eval_retrieval   # 检索 hit@k / MRR
python -m qa.eval_qa 8               # 端到端 18 题（8 = top_k，约 1 分钟、¥0.1）
```

**已知限制**（写在各模块文件头，此处只列最要紧的三条）：

1. 跨语言靠"中文问题 → 英文关键词"翻译，多一次模型调用；接上 embedding 后可换成向量检索对比。
2. 表格竖排：`chap04a` p3 的动物表被抽成 132 行，列关系丢失。要出"按规则表判断 frog 属于哪类"这类题必须先做表格还原。
3. 评估是开卷场景：黄金集的答案就出在这 199 页里，模型看到的是原文，所以 18/18 不代表泛化能力，只证明链路没断。
